# Iris Dataset Analysis with Pandas, Seaborn, and Matplotlib

This project demonstrates exploratory data analysis (EDA) on the classic **Iris dataset** using Python libraries.

## 📌 Features
- Load the Iris dataset from CSV (`iris.csv`)
- Display:
  - Basic dataset information (`df.info()`)
  - Summary statistics (`df.describe()`)
  - Species count distribution
- Perform univariate and multivariate analysis:
  - Histograms of feature distributions
  - Boxplot comparing sepal length across species
  - Pairplot to visualize feature relationships
